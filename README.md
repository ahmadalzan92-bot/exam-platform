# 🐄 منصة الامتحان المحوسب — علوم الإنتاج الحيواني

> **إعداد وتصميم: المهندس أحمد الزن**

منصة ويب احترافية (تعمل بدون إنترنت وبدون تثبيت أي برامج) لخوض امتحانات محوسبة في علوم الإنتاج الحيواني، مع تصحيح فوري بعد الإنهاء، وبنك أسئلة تلقائي يجمع كل إجاباتك الخاطئة لتُعيد الامتحان بها.

## 🚀 طريقة التشغيل

### الطريقة الأولى (الأفضل — تحفظ النتائج وبنك الأخطاء بشكل دائم)

1. افتح المجلد `exam-site`.
2. انقر بزر الفأرة الأيمن على ملف `serve.ps1` ← **Run with PowerShell**.
   (أو من موجّه الأوامر داخل المجلد: `powershell -ExecutionPolicy Bypass -File serve.ps1`)
3. سيفتح المتصفح تلقائياً على: `http://localhost:8080`

### الطريقة الثانية (الأبسط — بدون خادم)

انقر نقراً مزدوجاً على `index.html` مباشرة.

> ⚠️ ملاحظة: عند الفتح المباشر للملف (`file://`) قد لا يسمح بعض المتصفحات بحفظ النتائج وبنك الأخطاء بشكل دائم، لذلك تظهر رسالة تنبيه في الأعلى. كل شيء يعمل، لكن الحفظ يكون مؤقتاً حتى إغلاق الصفحة. للحفظ الدائم استخدم `serve.ps1`.

## 🧭 الاستخدام

1. **الرئيسية:** اختر أحد الامتحانات الشاملة (100 سؤال)، أو:
   - **امتحان شامل عشوائي (100 سؤال)** من كامل الأسئلة الـ 713.
   - **تدريب سريع (10 أسئلة)**.
   - **امتحان من بنك الأخطاء** (بعد أن يصبح لديك أخطاء).
2. **شاشة الإعداد:** اختر المصدر وعدد الأسئلة (الكل / 10 / 25 / 50 / 100 / عدد مخصص)، ثم اضبط: خلط الخيارات، خلط الأسئلة، التصحيح الفوري، والمؤقت.
3. **شاشة الامتحان:** أجب عن الأسئلة، وعلّم أي سؤال للمراجعة، وتنقّل عبر خريطة الأسئلة الجانبية.
4. **النتيجة:** النسبة، التقدير، تحليل المحاور، ومراجعة كل سؤال بالإجابة الصحيحة واختيارك، مع فلاتر (الخاطئة / بدون إجابة / الكل).
5. **بنك الأخطاء:** راجع أسئلتك الخاطئة، اعرض الإجابة الصحيحة، أو ابنِ امتحاناً جديداً منها.
6. **سجل النتائج:** تابع تطور مستواك وصدّر السجل.

## 🔧 ملاحظات تقنية

- المنصة مكتوبة بـ HTML/CSS/JavaScript خالص، **بدون أي مكتبات خارجية** (الخطوط فقط من Google Fonts، وتعمل بخط النظام إن لم يوجد إنترنت).
- البيانات تُحفظ محلياً في متصفحك فقط (localStorage) — لا يوجد خادم ولا إرسال لأي بيانات.
- لتحديث بنك الأسئلة: استبدل ملف `data/questions.js` بملف جديد بنفس البنية:

```js
window.EXAM_DATA = {
  totalQuestions: 713,
  sets: [
    {
      id: "set1",
      chapters: ["المحور الأول: ...", "..."],
      questions: [
        { chapter: "المحور الأول: ...", q: "نص السؤال؟", options: ["خيار", "خيار", "خيار", "خيار"], answer: 0 }
      ]
    }
  ]
};
```
> `answer` هو رقم الخيار الصحيح (يبدأ من 0).
